6. Cloud chip on MT5 (robot panel)

CLOUD CONNECTING CLOUD CONNECTED CLOUD PAUSED

What each state means

  • CONNECTING — trying to sync Supabase
  • CONNECTED — heartbeat OK
  • PAUSED — EA stopped ea_sync (saves bill)

How to pause / resume

  • Tap the cloud chip on the chart
  • Admin: Search MT5 → PAUSE CLOUD
  • Auto: 3 days with no open positions → pause
Note: Website LIVE UPDATE ≠ robot cloud chip. LIVE UPDATE only speeds the phone dashboard. PAUSED robot will look Offline on the site until resumed.

8. Update robot to V6.5.6

Short path: Flat account → Settings → UPDATE ROBOT → wait for MT5 restart → attach GPE Neon Cloud V6.5.6 → confirm version 6.5.6 on the website.

Before you tap Update

  1. Login at https://gpealgo.app.
  2. MT5 must be approved and the robot LIVE / CONNECTED.
  3. Close all positions on that account. Update is blocked while trades are open.
  4. On the VPS: AutoTrading ON and Allow DLL imports ON (needed for the updater).

A — Update from the website (recommended)

1

Open Settings

Find the Robot Update card.

2

Read both lines

Top line = cloud robot + website version (should be 6.5.6). Bottom line = robot on your VPS.

3

Check, then Update

Tap Check for update if shown, then tap UPDATE ROBOT.

4

Wait on the VPS

The VPS downloads one EX5 only (GPE Neon Cloud V6.5.6.ex5), restarts MT5 portable, and removes old GPE Neon Cloud EX5 names.

5

Re-attach

In Navigator → Experts, attach GPE Neon Cloud V6.5.6 on the chart. Confirm the Settings card shows Robot 6.5.6.

Figure E — Flat → UPDATE ROBOT → VPS installs one file → attach V6.5.6

B — Manual update on the VPS

Use this only if the website button does nothing.

  1. Make sure the account is flat, then close MT5.
  2. Open PowerShell in the portable MQL5\Experts folder and run:
powershell -ExecutionPolicy Bypass -File .\GPE_Update.ps1 -Force
  1. Check MQL5\Files\gpe-update.log.
  2. Start again with Start_MT5_GPE.bat, then attach GPE Neon Cloud V6.5.6.

C — Fresh VPS install

  1. Settings → Download MT5 portable (zip V6.5.6).
  2. Extract on the VPS → run Start_MT5_GPE.bat.
  3. Login broker → attach GPE Neon Cloud V6.5.6 → submit the MT5 number if needed.

How to confirm success

Robot panel

Header / footer shows V6.5.6.

Website Settings

Bottom line: Robot 6.5.6 on the VPS.

Navigator

One main file: GPE Neon Cloud V6.5.6 (not many old V6.3–V6.5.5 copies).

Cloud chip

Returns to CONNECTED after restart (unless paused).

If update fails

Update blocked

Close all positions first, then tap UPDATE ROBOT again.

Version unchanged

Already on 6.5.6, or flag did not reach VPS. Try manual -Force.

MT5 will not reopen

Delete MQL5\Files\GPE_UPDATE_NOW.txt if it remains. End leftover terminal64 / PowerShell, then run Start_MT5_GPE.bat.

Empty chart after update

Re-attach GPE Neon Cloud V6.5.6. The updater keeps one EX5 name only.

Phone notifications

  • Settings → Enable phone notifications. Keep the PWA on the Home Screen for alerts when the browser is closed.
  • You do not compile on the VPS. The website / updater replaces the EX5 for you.

10. Quick troubleshooting

Robot did not confirm START

Turn LIVE UPDATE on. Chip CONNECTED. Symbol name exact. Wait <20s. Check Experts for symbol_on / gpe_on.

Instrument became another pair

Check ACCOUNT 1/2. Do not edit same MT5 on two phones. Re-save instruments on the correct account.

Margin calc error spam

Usually empty balance / bad symbol with START ON. START OFF or Pause cloud. V6.5.6 logs at most once per minute.

Presets RLS error

Ask admin to fix ownership or delete stale presets row for that MT5, then SEND again.

UPDATE ROBOT stuck

Account flat? Robot LIVE? Then try VPS manual GPE_Update.ps1 -Force. See section 8.

Many old EX5 names

After a successful V6.5.6 update only one file should remain. Attach V6.5.6 and remove leftover names if needed.
